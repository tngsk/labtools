# Arduino プロジェクト一覧

このディレクトリには、M5Stack社のATOM LiteやM5StickC Plus、および一般的なArduino向けに作成された各種プロジェクトが格納されています。
以下に各プロジェクトの概要、使い方、および想定される接続方法をまとめました。

## ATOM Lite 向けプロジェクト

### 1. ATOMLite-DFPlayerMini
- **概要**: DFRobot製のDFPlayer Mini (MP3プレイヤーモジュール) を制御するデモプログラムです。
- **使い方**: 起動時にDFPlayer Miniを初期化し、その後トラック1とトラック2を順番に再生します。シリアルモニタ (115200bps) で状態を確認できます。
- **接続方法**:
  - ATOM Lite `Pin 33` (RX) <---> DFPlayer Mini `TX`
  - ATOM Lite `Pin 23` (TX) <---> DFPlayer Mini `RX`

### 2. ATOMLite-I2CHub-ToF_VL53L0X
- **概要**: TCA9546A (I2Cマルチプレクサ) を使用し、最大3つのVL53L0X (ToF距離センサー) から同時に高精度な距離データを取得するデータロガーです。
- **使い方**: 起動すると50ms間隔で測定を行い、シリアル通信でデータを出力します。ATOMのボタンAを押すと、出力フォーマットをJSONとCSVで切り替えることができます。PC側でデータを受信するためのPythonスクリプトも同梱されています。
- **接続方法**:
  - I2C (SDA: `Pin 26`, SCL: `Pin 32`) に TCA9546A を接続。
  - TCA9546A の各チャンネルに VL53L0X を接続。

### 3. ATOMLite-KeyUnit
- **概要**: M5StackのKey Unit (ボタンユニット) の入力を読み取り、接続されたLEDを制御するシンプルなプログラムです。
- **使い方**: ボタンを押している間、LEDが青色に点灯し、シリアルモニタに `1` が出力されます。離すと消灯し `0` が出力されます。
- **接続方法**:
  - Key Unit: `Pin 32`
  - SK6812 LED (テープLED等): `Pin 26`

### 4. ATOMLite-LED-Simple
- **概要**: 60個のNeoPixel (WS2812B/SK6812等) テープLEDを制御し、流れるようなテール効果（残像）付きのアニメーションを表示します。
- **使い方**: 起動すると自動的にアニメーションが始まります。ATOMのボタンAを押すと、アニメーションが最初からリセットされます。
- **接続方法**:
  - NeoPixel テープLED (60個): `Pin 26`

### 5. ATOMLite-RGBLED-SK6812
- **概要**: 3つのNeoPixel (SK6812) LEDを青色に点灯させる基本テストプログラムです。
- **使い方**: 起動するだけで、指定されたLEDが青色に光ります。
- **接続方法**:
  - NeoPixel LED (3個): `Pin 26`

### 6. ATOMLite-TapeLED-Animation
- **概要**: Wi-Fiに接続し、OSC (Open Sound Control) 経由でLEDの色を受信しながら、テール効果付きのアニメーションをテープLEDに表示します。
- **使い方**: 起動時にWi-Fiルーター（SSID: `ngsk-lab`）に接続します。ポート `9001` で `/Color` というOSCメッセージ (引数はRGBの3つの整数) を待ち受け、指定された色でアニメーションを描画します。ATOMのボタンAを押すと、現在のIPアドレスをシリアルに出力し、アニメーションをリセットします。
- **接続方法**:
  - NeoPixel テープLED (60個): `Pin 26`

### 7. ATOMLite-ToF4M
- **概要**: VL53L1X (長距離ToFセンサー, 最大4m) を使用して距離を測定するプログラムです。
- **使い方**: 起動後、連続して距離を測定し、シリアルモニタに距離 (mm) を出力します。ATOMのボタンAを押すと `A` と出力されます。
- **接続方法**:
  - VL53L1X: Groveポート (I2C) 等を使用して接続

### 8. ATOMLite_LED-ButtonUnit
- **概要**: Button Unitが押されるたびに、3つのNeoPixel LEDの色を変化させるプログラムです。
- **使い方**: ボタンを押すとRGB値が徐々に加算され、LEDの色が変化します。ボタンを離すとLEDは消灯します。
- **接続方法**:
  - Button Unit: `Pin 32`
  - NeoPixel LED (3個): `Pin 26`

### 9. ATOMLite_TapeLED
- **概要**: Wi-Fi経由でOSC通信を受信し、テープLEDの全体の色をリアルタイムに制御するプログラムです。
- **使い方**: 起動時にWi-Fiルーター（SSID: `ngsk-lab`）に接続します。ポート `9001` で `/Color` メッセージを受け取ると、テープLED全体の色がその色に変更されます。
- **接続方法**:
  - NeoPixel テープLED (60個): `Pin 26`


## M5StickC Plus 向けプロジェクト

### 10. M5Stick-Acc-BLE
- **概要**: 内蔵のIMU (慣性計測装置) から加速度データを取得し、画面に表示するとともに、Bluetooth Serial (BLE相当) と通常のシリアル通信で送信するプログラムです。
- **使い方**: 起動すると画面にX, Y, Zの加速度がリアルタイムに表示されます。PCやスマートフォンからBluetooth (`M5StickC` というデバイス名) で接続し、シリアルデータを受信できます。
- **接続方法**:
  - M5StickC Plus 本体のみで動作（外部接続不要）

### 11. M5StickCp-GESTURE
- **概要**: PAJ7620U2 ジェスチャーセンサーを使用して、手の動き（上下左右、回転など）を認識するプログラムです。
- **使い方**: センサーの前で手を動かすと、認識されたジェスチャー（例: `Up`, `Down`, `Left`, `Right` など）がシリアルモニタに出力されます。
- **接続方法**:
  - PAJ7620U2センサー: Groveポート (I2C) 等を使用して接続


## 一般的な Arduino 向けプロジェクト

### 12. Blink
- **概要**: Arduinoの基本であるLED点滅 (Blink) プログラムを少し改造し、点滅間隔が徐々に長くなるようにしたプログラムです。
- **使い方**: 起動すると本体の内蔵LEDが点滅します。シリアルモニタ (9600bps) を開くと、現在の遅延時間 (timer) が出力され、ループごとに10msずつ遅延が増加していくのが確認できます。
- **接続方法**:
  - Arduino本体のみ（内蔵LED `LED_BUILTIN` を使用）
